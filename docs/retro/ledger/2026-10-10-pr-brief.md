## 4. Module insights

- server
  - `@fastify/rate-limit` is only registered when `nodeEnv !== 'test'`, so 429 tests need a non-test app.
  - LLM adapters throw `ExternalServiceError('… failed schema validation')` (OpenAI/Anthropic), OpenRouter a plain `Error`; `container.github()` throws `ConfigError` (a missing GitHub token must not be reported as `missing_key`).
  - Fastify passes `null` for a POST without payload and rejects an empty body with `Content-Type: application/json` before any Zod preprocess.
  - In-process per-PR lock must have no `await` between `has` and `set`.
- client
  - `@testing-library/user-event` is not installed; use `fireEvent`.
  - No component uses `@media`/CSS modules; a layout test needs a `matchMedia` hook (`useMediaQuery`) and a data attribute.
  - Strict Mode: dedupe auto-mutations with a module-scope `Set`, write the cache in `useMutation` options.
  - `SmartDiffGroup` starts collapsed for some roles; deep links must open the group.
- reviewer-core: `wrapUntrusted` escapes only the exact lowercase closing tag.
- e2e: the runner substitutes only `{BASE}` and the PR URL contains a uuid, so "reload" means re-navigating through the list; seeded `pr_files` for #482 have no `patch`; the hermetic stack's cold Next compile exceeds the 60 s `agent-browser open` timeout (same as last run).
- tooling: `scripts/e2e.sh` rewrites `client/next-env.d.ts` to `.next-e2e` and leaves it modified; `run-plan` is `disable-model-invocation`.

Suggested engineering-insights entries:
- server: rate limit off under `NODE_ENV=test`; adapter error shapes; Fastify empty-body handling.
- client: `user-event` not installed; `matchMedia` hook for layout tests; Strict Mode dedupe pattern.
- e2e: runner `{BASE}` only; cold-compile timeout; seeded PR #482 files have no patch.
- tooling: `e2e.sh` leaves `client/next-env.d.ts` modified.
